# OpenAI(LLM) 연동 규칙

## 키 보호
- API 키는 환경변수에서만 읽는다. 코드·로그·응답·에러 메시지에 절대 노출 금지.
- 요청/응답 로깅 시 키와 민감한 사용자 데이터는 마스킹한다.

## 신뢰성
- 모든 호출에 **타임아웃**(connect / read)을 설정한다.
- **재시도**: 일시적 오류(5xx, 네트워크)에 exponential backoff. 무한 재시도 금지(최대 횟수 제한).
- **429(rate limit)**: 별도 처리 — `Retry-After`를 존중하고 backoff. 사용자에게는 "잠시 후 다시 시도" 류 메시지.
- 호출 지연이 길 수 있으므로, 사용자 요청 흐름을 막지 않도록 필요 시 비동기/큐 처리를 고려한다.

## 비용 / 출력 관리
- `max_tokens`로 응답 길이 상한을 둔다.
- 작업 난이도에 맞는 모델을 선택한다(간단한 작업에 과한 모델 금지).
- 불필요하게 큰 컨텍스트를 매 호출마다 보내지 않는다.

## 프롬프트 안전성
- 사용자 입력이 프롬프트에 들어갈 때 prompt injection에 대비한다: 시스템 프롬프트와 사용자 입력을 분리하고, 사용자 입력을 검증·정규화한다.
- LLM 출력을 그대로 신뢰해 실행/쿼리/렌더링하지 않는다(검증·이스케이프 후 사용).
