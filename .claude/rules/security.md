# 보안 규칙

## 시크릿 관리
- AWS S3 키, DB 비밀번호, OpenAI API 키를 **코드에 하드코딩 금지**.
- 환경변수 또는 외부 설정(`application-*.yaml` + 환경변수 주입, 또는 비밀 관리 서비스)으로 분리.
- 시크릿이 들어간 설정 파일은 `.gitignore`에 포함. 커밋되는 예시에는 placeholder만 둔다.
- 로그·예외 메시지·HTTP 응답에 시크릿을 절대 출력하지 않는다.

## SQL (MyBatis)
- 파라미터 바인딩은 `#{}`(PreparedStatement)를 사용한다.
- `${}`(문자열 치환)는 **금지**. 불가피한 동적 컬럼/정렬은 화이트리스트로 검증한 뒤에만 사용.

## 입력 검증
- 컨트롤러 진입 지점에서 검증한다(`@Valid` + Bean Validation).
- 파일 업로드(S3): 확장자·MIME·용량 제한, 파일명 정규화(경로 조작 방지).
- 외부 입력이 그대로 쿼리·프롬프트·파일경로·로그에 들어가지 않게 한다.

## 응답
- 내부 예외/스택트레이스를 사용자에게 노출하지 않는다(전역 예외 핸들러에서 표준 메시지로 변환).
